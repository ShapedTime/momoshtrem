Cinematic dark

A redesign of momoshtrem, the concierge and control room for a personal media library that plays in Infuse on Apple TV. Artwork carries the colour and the chrome recedes. A single amber accent, the colour of a cat's eyes in the dark, marks what to do next.

Key decisions

What changes from today's red-on-black catalog, and why.

One accent: cat-eye amber

Lavender was explored side by side and rejected: it competes with the needs-review violet. Amber ties the logo, the loader and every primary action into one story. Red and blue are gone.

The primary action tells the truth

Add → Find a torrent → Downloading → Ready in Infuse, with a four-step indicator. "Ready" is a state with a copyable WebDAV path and a how-to, never a disabled button.

Torrent search is a stable sheet

Full height from the first frame, sticky search and chips, a reasoned best match, wrapping release names, Add that never stretches, and filters that say exactly which ones hide everything.

Titles and status without hover

Every card shows title, year and a status pill on the artwork. Rails have arrows on pointer devices and a peeking next item on touch.

Long seasons stay short

Compact episode rows, range chips (1–10, 11–20… or arcs for One Piece), jump-to-episode, "show earlier (all watched)" and a virtualised list.

Noir, a black cat

Proposed mascot name. In the dark you only see its eyes: they're the loader, the favicon's cut-outs and the face of "Ask momoshtrem". Never in serious errors.
